# Eternal Wanderer - Полу-АФК РПГ

## Описание проекта
**Eternal Wanderer** - это полу-АФК (AFK) ролевая игра, где герой автоматически путешествует по процедурно-генерируемому миру, взаимодействует с NPC, сражается с врагами, выполняет квесты и развивается через систему навыков.

## Основные возможности

### 🌍 Генеративный мир
- Процедурная генерация ландшафта с использованием шума Перлина
- Различные биомы: равнины, леса, горы, водоёмы
- Динамическое расширение мира при исследовании
- Система рек и природных объектов

### 🤖 Автоматическое путешествие (AFK)
- Автономное перемещение героя по миру
- Система ИИ для принятия решений в реальном времени
- Автоматическое реагирование на события и встречи

### 👥 Взаимодействие с жителями
- NPC с уникальными личностями и характерами
- Система отношений и репутации
- Диалоговая система с вариантами ответов
- Эмоциональная система для NPCs

### ⚔️ Боевая система
- Автоматические и тактические бои
- Различные типы врагов с уникальным поведением
- Система способностей и умений
- Combat events для обработки боевых ситуаций

### 📜 Квесты и задания
- Разнообразные типы квестов: fetch, kill, delivery, exploration
- Система прогресса выполнения
- Награды и последствия выполнения

### 🎯 Система развития
- Прокачка уровня и опыта
- Дерево навыков с категориями: Combat, Magic, Crafting, Social, Survival
- Автоматическое улучшение навыков
- Система очков навыков

### 🎒 Инвентарь и предметы
- Система инвентаря с предметами
- Различные типы предметов и экипировки

### 💾 Сохранение прогресса
- Система сохранения/загрузки игры
- Менеджер сохранений

## Сборка проекта

### Требования
- Visual Studio 2019 или новее
- C++17 или выше
- SFML библиотека (для графики и звука)

### Компиляция
1. Откройте `EternalWanderer.vcxproj` в Visual Studio
2. Убедитесь, что SFML настроен в проекте
3. Соберите проект (Ctrl+Shift+B)

### Запуск
Запустите скомпилированный исполняемый файл.

## Управление

- **Пробел** - Пауза/продолжение
- **I** - Открыть инвентарь
- **K** - Открыть навыки
- **M** - Показать карту
- **Q** - Журнал квестов
